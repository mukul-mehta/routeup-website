Outline:

- Transport: Unix domain socket per user.
- Path: `~/.routeup/agent.sock` (or `$XDG_RUNTIME_DIR/routeup/agent.sock` on Linux).
- Permissions: directory 0700, socket 0600.
- Wire format: JSON over HTTP/1.1.
- Auth: filesystem permissions only.
- Versioning: `/v1/` URL prefix.
