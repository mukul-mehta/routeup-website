---
title: Tokens and allow patterns
description: How routeup authorizes persistent, scoped claims outside the public namespace.
---

Tokens authorize persistent public route claims on a routeup server. They are created by the server operator and handed to clients out-of-band.

## Token shape

Token secrets use the `sk_routeup_` prefix and are shown once when created. The server stores a hash, not the plaintext secret.

## Allow patterns

An allow pattern grants exactly one public label under a suffix:

```txt
*.routeup.dev
```

That matches `example-app.routeup.dev`. It does not match `routeup.dev` or `api.example-app.routeup.dev`.

This is why public route names are single labels. Use `api-example-app` instead of `api.example-app` for a public route.
