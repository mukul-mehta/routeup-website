---
title: routeup routes
description: List the active routes registered with the local agent.
---

`routeup routes` lists every route currently registered with the local agent.

```bash
routeup routes
```

Example output:

```txt
NAME       TARGETS  PUBLIC                      PATHS      PID    AGE  CWD
example-app      /:8080   https://example-app.routeup.dev   all paths  41021  12s  /Users/me/example-app
api.example-app  /:9080   -                           -          41044  8s   /Users/me/example-app
```

Columns:

- **Name**: the active dotted route name.
- **Targets**: path and port pairs such as `/:8080`; multiple targets are
  comma-separated.
- **Public**: the public URL associated with the process that owns this local
  claim, or `-` when none is associated.
- **Paths**: that owner's publicly exposed path scope, or `-` when none is
  associated.
- **PID**: the process holding the local route.
- **Age**: how long the current claim has been active.
- **CWD**: the holding process's working directory.

The command does not print a `LOCAL` column. Derive the local URL mechanically as
`https://<name>.localhost`.

A standalone `routeup expose` may reuse this route's targets while running under
a different process. That separate tunnel is not annotated on the local claim's
row.

## When the agent is not running

If the agent is not running, there are no active routes and the command says so.
Routes exist only while the process that registered them is alive, the agent
keeps its registry in memory, and each live `serve` re-asserts its claim if the
agent restarts.
