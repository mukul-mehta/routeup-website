---
title: routeup inspect
description: Show captured request and response data for a specific request.
---

`routeup inspect` shows the retained request and response data for a request
that was recorded by an opted-in route.

```bash
routeup inspect <request-id>
```

Get the request id from `routeup logs`:

```bash
routeup logs example-app --follow
# 12:41:03 public example-app POST /api/webhooks/github 200 38ms req_abc123

routeup inspect req_abc123
```

## Enabling capture

Capture is disabled by default. Enable it per-route in `routeup.json`:

```json
{
  "name": "example-app",
  "port": 8080,
  "capture": {
    "request": true,
    "response": true,
    "redact_headers": ["authorization", "cookie"]
  }
}
```

`request` captures incoming headers and body. `response` captures the upstream's
headers and body. Both are independent — you can enable either or both.

Headers listed in `redact_headers` are omitted from the captured copy but are
still forwarded to the upstream service unchanged.

## Retention

Captured data is stored in the same in-memory ring buffer as request logs (last
10,000 entries). It is cleared when the agent restarts. Each captured message is
bounded to 256 KiB — larger bodies are captured as a prefix and marked
`partial`.

## Privacy

`routeup inspect` is only accessible over the local Unix socket (mode 0600).
It is not reachable from the network.
